# winget status

This fork has no published winget package.

The inherited MechanicWB manifests referenced the original app's installer, package ID, and publisher. They have been removed from this fork to avoid installing the original app under the fork's instructions.

If a winget package is added later, use this fork's own package ID, publisher, installer URL, and verified SHA256. Until then, build from source or use this fork's own releases as described in README.md.
