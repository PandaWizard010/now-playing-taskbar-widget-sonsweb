# Fork description

**Now Playing - Sonos Fork** is an independent development fork maintained by PandaWizard010, based on **Now Playing - Taskbar Widget** by MechanicWB.

The goal is Sonos playback support. The Sonos integration kit has not yet been merged, so the checked-in playback implementation currently targets Spotify.

This fork has no Pro purchase flow or Microsoft Store listing. It does not activate the original application's paid add-on.
